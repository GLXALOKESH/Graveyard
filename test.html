Identify the Undead.

Resources that drain your budget while providing zero value to production. We find them based on strict, transparent rules.

Idle EC2 Instances

Compute resources that are powered on but doing absolutely nothing, accumulating hourly charges.

Rule: CPU < 2% for 7 days

Unattached EBS Volumes

Disks that were detached when a server was terminated but never deleted. Silent storage costs.

Rule: State = Available > 14 days

Orphaned IPs

Elastic IP addresses that are reserved but not attached to any running instance. AWS penalizes you for hoarding these.

Rule: Unassociated EIPs

Ancient Snapshots

Backups from years ago tied to infrastructure that no longer exists. Rarely needed, always billed.

Rule: Age > 90d & No active AMI
